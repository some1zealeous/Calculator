# 💻 Windows 11 Calculator

A sleek, responsive calculator inspired by Windows 11 — built using **HTML**, **CSS (Bootstrap 5.3)**, and **JavaScript**.

---

## ✨ Features

- Dual display: **Expression** + **Current Entry**
- Basic math: `+`, `−`, `×`, `÷`, `mod`
- Functions: `x²`, `1/x`, parentheses
- **Keyboard support** & smooth UI
- Responsive glassmorphic design

---

## 🚀 Quick Start

1. Clone or download the project  
2. Open `index.html` in your browser  
3. Start calculating ⚡

---

## 🎯 Controls

| Key           | Function           |
|---------------|--------------------|
| 0–9, `+`, `-`, `*`, `/`, `.` | Input & operators |
| `Enter` / `=` | Evaluate expression |
| `Backspace`   | Delete last input  |
| `C` / `Esc`   | Clear all          |
| `%`           | Modulo             |
| `x²`, `1/x`   | Math functions     |

---

## 📁 Files

- `index.html` – Calculator layout  
- `style.css` – Styling (Bootstrap + custom)  
- `script.js` – Logic & interaction
